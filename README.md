# Sales Data Visualization Project

## Project Overview

This project analyzes sales data using Python. The data is loaded from a CSV file, basic sales metrics are calculated, and charts are created to visualize the results.

## Objectives

-Load and explore sales data
-Calculate sales metrics
-Create visualizations using charts
-Generate a simple sales report

## Technologies Used

-Python
-Pandas
-Matplotlib

## Project Structure

sales-data-visualization/

├── analysis.ipynb

├── sales_data.csv

├── analysis_report.md

├── requirements.txt

└── visualization.ipynb


## Metrics Calculated

1 Total Sales
2 Average Sales
3 Highest Sale

## Charts Created

 Bar Chart: Sales by Product
 Pie Chart: Sales Distribution

## Installation

Install the required libraries:

pip install -r requirements.txt


## Output

The project displays:

* Dataset information
* Sales metrics
* Bar chart visualization
* Pie chart visualization

## Conclusion

This project demonstrates basic data analysis and visualization using jupyter notebook , Pandas, and Matplotlib.
